# 验证记录

验证环境：Windows、Flutter 3.47.7、Dart 3.13.5、Android 15 / API 35、x86_64。专用模拟器 `eden_review`，画面 750 × 1624，密度 320，逻辑宽度 375。

- 静态检查：`flutter analyze`。
- 自动测试：金额与优惠、购物车选项合并、存储恢复、筛选、72 个路由在 375 × 812 / 320 × 740 两档布局，以及点餐点击流程。
- Android 集成测试：逐路由保存 PNG，并点击完成点餐、配送地址、卡片确认、下单、司机查找和配送地图流程。
- iOS 未在 Windows 上构建；Web 工程可运行，未纳入此次设备验收。

测试截图使用内存演示状态，不覆盖应用正常运行时保存的数据。截图展示当前画面；长列表通过滚动查看。

详细结果见本目录 `validation/` 下的检查和测试日志，完整截图见 [页面索引](SCREENS.md)。
